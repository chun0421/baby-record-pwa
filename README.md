# 寶寶生理紀錄 PWA

可安裝到 iPhone／Android 主畫面的家庭生理紀錄工具。使用 Google 登入與 `drive.file` 權限，資料直接保存在使用者自己的 Google 試算表。

正式網站：<https://chun0421.github.io/baby-record-pwa/>

## 功能

- 首次登入後自動建立 Google 試算表資料庫
- 喝奶、大小便、睡眠、體溫、黃疸、成長與副食品
- 睡眠開始／醒來計時
- 邀請家人的 Gmail 共同編輯
- 使用 Google Picker 加入共享資料庫
- 離線開啟與待同步紀錄

此專案不使用 Apps Script、付費伺服器或 Apple Developer Program。
